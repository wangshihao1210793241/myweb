# 从0开始学习AI编程

AI 正在改变编程的方式，即使你不是算法工程师，也能借助 AI 工具大幅提升开发效率。本系列从零开始，带你一步步掌握 AI 编程的核心概念和实战技能。

## 什么是 AI 编程？

AI 编程不是让你去训练大模型，而是：

- **用 AI 辅助写代码** — 让 AI 帮你生成、优化、调试代码
- **用 AI 理解代码** — 让 AI 帮你阅读和理解陌生的代码库
- **调用 AI 的 API** — 在你的项目中集成 AI 能力

## 学习路线

```
第 1 阶段：AI 工具使用
  ├── 学会使用 ChatGPT / Claude 等对话式 AI
  ├── 学会使用 AI 编程助手（如 Cursor、Copilot）
  └── 掌握 Prompt 技巧（如何向 AI 提问）

第 2 阶段：AI API 接入
  ├── 了解 OpenAI API / Claude API 的基本调用
  ├── 用 Python 调用 AI 接口
  └── 在 Java/Vue 项目中集成 AI 能力

第 3 阶段：AI 应用开发
  ├── 构建 AI 对话机器人
  ├── RAG（检索增强生成）应用
  └── AI Agent（智能体）开发
```

## 推荐工具

| 工具 | 用途 | 说明 |
|------|------|------|
| ChatGPT | AI 对话 | 日常问答、代码生成 |
| Claude | AI 对话 | 长文本理解、代码分析 |
| Cursor | AI 编程 IDE | 内置 AI，直接在编辑器中写代码 |
| GitHub Copilot | 代码补全 | VS Code 插件，自动补全代码 |

## 第一步：学会向 AI 提问

好的提问 = 清晰的背景 + 具体的需求 + 期望的输出格式

```text
❌ 差的提问：
  "帮我写个接口"

✅ 好的提问：
  "我用 Spring Boot 开发一个用户管理系统，
   需要一个根据用户 ID 查询用户信息的 GET 接口，
   用户实体包含 id、name、email、age 字段，
   请给出 Controller 和 Service 层的代码"
```

## 总结

AI 编程的核心不是替代你，而是**放大你的能力**。掌握 AI 工具的使用，会让你的开发效率提升数倍。
